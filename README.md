# Drake & Key — Grid-Based Layout Assignment

This project is a one-page landing page for a fictional brand called Drake & Key. The design uses a dragon key logo and a simple navy, white, and gold colour scheme.

## Files

- `index.html` — Main webpage structure
- `style.css` — Page styling, Grid, Flexbox, and responsive design
- `script.js` — Mobile menu and basic interactions
- `logo.png` — Logo used on the webpage

## Features

- CSS Grid for the main page sections
- Flexbox for the navigation and buttons
- Responsive design for desktop, tablet, and mobile
- Semantic HTML elements
- Hover effects
- Simple logo animation
- Mobile navigation menu
- Footer with logo credit
